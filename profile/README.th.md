เราสร้างส่วนเชื่อมต่อ Home Assistant ไคลเอนต์เสียง บริดจ์อุปกรณ์ เครื่องมือวางผัง และคู่มือติดตั้งที่นำกลับมาใช้ได้ โครงการสาธารณะเชื่อมงานบ้านอัตโนมัติในทางปฏิบัติเข้ากับบิลด์ที่ทำซ้ำได้ ข้อกำหนดสัญญาที่ชัดเจน และขั้นตอนกู้คืนที่มีเอกสาร เริ่มจากโครงการเดียวได้ แต่ละโครงการมีวิธีติดตั้งและฮาร์ดแวร์ที่รองรับของตนเอง

![แผนผังบทบาทโครงการ HA Homelab: อุปกรณ์ เสียง การตั้งค่า เครื่องมือวางผัง และการทดสอบ](https://raw.githubusercontent.com/ha-homelab/.github/main/assets/profile/ecosystem.th.svg)

แผนผังนี้จัดกลุ่มงานที่เกี่ยวข้อง ไม่ได้หมายความว่าทุกโครงการต้องติดตั้งร่วมกันหรือเชื่อมต่อกับโครงการอื่นโดยอัตโนมัติ

## มีอะไรใหม่ — ตุลาคม 2026

- **วาดและเผยแพร่บ้านของคุณภายใน Home Assistant โดยตรง** [Home Studio](https://ha-homelab.github.io/home-studio/install.html#native-studio) นำตัวแก้ไข 2D/3D แบบเฟอร์นิเจอร์และสวน 206 แบบ และภาษาตัวแก้ไข 24 ภาษามาไว้ใน HA วาดห้อง เชื่อมโยงพื้นที่และอุปกรณ์ HA แล้วเลือก **Save draft** จากนั้น **Publish family view** เพื่ออัปเดต **3D Home**
  [โหมด Dry run](https://github.com/ha-homelab/home-studio/blob/main/docs/dry-run.md) ให้สำรวจผังที่ติดตั้งแล้วโดยบล็อกคำสั่งไปยังอุปกรณ์ [คู่มือเริ่มใช้งาน](https://github.com/ha-homelab/home-studio/blob/main/docs/first-session.md) อธิบายการเริ่มจากตัวอย่าง การกู้คืนฉบับร่าง และการเก็บรักษางานเมื่อใช้งาน 3D ไม่ได้
- **ทางเลือกเพิ่มขึ้นในการใช้อุปกรณ์เดิมต่อ** [EchoMuse](https://github.com/ha-homelab/ha-echomuse) มีเอกสารเส้นทางเสียง เพลง และ BLE บน Echo Dot 2 ส่วน [ZAC93 + ESP32](https://github.com/ha-homelab/zac93-esp32) อธิบายบริดจ์ Z-Wave โครงการ RF, Zigbee และ Tuya ด้านล่างครอบคลุมอุปกรณ์กลุ่มอื่น ความพร้อมของฮาร์ดแวร์ขึ้นกับแต่ละโครงการ โดย ZAC93 ยังรอการตรวจรับการทำงานกับอุปกรณ์จริง
- **การตั้งค่าสาธารณะและการกู้คืน** [Home Assistant](https://github.com/ha-homelab/home-assistant) มีไลบรารีระบบอัตโนมัติและสคริปต์ที่ใช้ซ้ำได้ รวมถึงข้อกำหนดการเชื่อมต่อ ส่วน [k3s self-healing](https://github.com/ha-homelab/k3s-self-healing) เผยแพร่เครื่องมือติดตั้ง สำรองข้อมูล และกู้คืน อินสแตนซ์เดียวที่ใช้พื้นที่เก็บข้อมูลภายในเครื่องไม่ได้ให้การสลับระบบเมื่อขัดข้องโดยอัตโนมัติ
- **ตรวจหลักฐานก่อนทำงานอัตโนมัติ** โครงการใหม่ด้านการตรวจวัด ทิศทางกล้อง และการเข้าถึง เสริมกับ[เครื่องมือชุมชน](https://github.com/ha-homelab/.github/blob/main/community-tools/README.th.md)สี่ตัวสำหรับย้ายเอนทิตี ตรวจที่มาของค่ามิเตอร์ ทดสอบสถานการณ์อัตโนมัติ และประเมินผลเสียง [DESLOC Lock Card](https://github.com/ha-homelab/ha-desloc-card) ใช้ปุ่มการทำงานเดียวที่เปลี่ยนตามสถานะ โดยยังต้องยืนยันการปลดล็อกอย่างชัดเจน

นี่คือภาพรวมที่เรียบเรียง ณ **19 ตุลาคม 2026** ดู README และรุ่นเผยแพร่ของแต่ละโครงการสำหรับสถานะและความเข้ากันได้ล่าสุด

## ติดตั้ง Home Studio ภายใน Home Assistant

ใช้ **Home Assistant 2026.10 หรือใหม่กว่า** และบัญชีผู้ดูแลระบบ
สำรองข้อมูล HA ก่อน หากติดตั้ง **home_floorplan** ที่สร้างขึ้นหรือปรับแต่งไว้แล้ว ให้อ่าน[แนวทางการย้ายระบบ](https://github.com/ha-homelab/home-studio/blob/main/docs/home-assistant-editor.md#existing-generated-homes)ก่อนแทนที่

1. ใน HACS เพิ่ม [`ha-homelab/home-studio`](https://github.com/ha-homelab/home-studio) เป็นที่เก็บแบบกำหนดเองในหมวด **Integration** ติดตั้งรุ่นเสถียรล่าสุดที่มี **`home_floorplan.zip`**
2. เริ่ม Home Assistant ใหม่ เปิด **Settings → Devices & services → Add integration** แล้วเลือก **Home Studio**
3. เปิด **Home Studio** จากแถบด้านข้าง วาดและจัดเฟอร์นิเจอร์ในห้อง เชื่อมโยงพื้นที่และอุปกรณ์ HA แล้วเลือก **Save draft**
4. เลือก **Publish family view** แล้วเปิด **3D Home** ตรวจสอบผังและการเชื่อมโยงด้วย **Dry run** ก่อนเปิดใช้การควบคุมอุปกรณ์จริง

การติดตั้งแบบเนทีฟใหม่ไม่ต้องใช้คำสั่ง Python รายการ YAML หรือโทเค็น API ดูขั้นตอนทั้งหมด การติดตั้ง ZIP ด้วยตนเอง และแนวทางสำหรับระบบที่ติดตั้งอยู่แล้วใน[คู่มือติดตั้งแบบเนทีฟ](https://ha-homelab.github.io/home-studio/install.html#native-studio)

## สำรวจโครงการ

### การตั้งค่าและความเชื่อถือได้

- **[home-assistant](https://github.com/ha-homelab/home-assistant)** — การตั้งค่าสาธารณะ ระบบอัตโนมัติและสคริปต์ที่รวมไว้ คู่มือติดตั้ง และข้อกำหนดการเชื่อมต่อ

- **[k3s-self-healing](https://github.com/ha-homelab/k3s-self-healing)** — Home Assistant บน k3s ที่ย้ายได้ การอัปเดตที่ต้องอนุมัติ ข้อมูลสำรองที่ตรวจสอบแล้ว และเครื่องมือกู้คืน

### เสียงและสื่อ

- **[asterisk-telephony](https://github.com/ha-homelab/asterisk-telephony)** — ตัวติดตั้งการผสานรวม Asterisk จากโครงการต้นทางที่ผ่านการตรวจสอบ แดชบอร์ดโทรศัพท์ SIP และการควบคุมเครื่อง Cisco พร้อมเส้นทางเสียง Assist แยกต่างหากและผลทดสอบการยอมรับที่บันทึกไว้
- **[ha-ottplay](https://github.com/ha-homelab/ha-ottplay)** — เอนทิตีเครื่องเล่นสื่อและรีโมตของ Home Assistant สำหรับเครื่องเล่นที่ลงทะเบียนผ่าน OTTPlay Control Server ที่มีอยู่ ความสามารถในการควบคุมขึ้นอยู่กับเครื่องเล่น
- **[ha-echomuse](https://github.com/ha-homelab/ha-echomuse)** — Echo Dot 2 กับ EchoMuse/emOS, Assist, เพลง เครื่องมือบ้านภายในระบบ และพร็อกซี BLE ที่ลงทะเบียนแยก เส้นทางรู้จำเสียงที่บันทึกไว้ใช้ผู้ให้บริการคลาวด์ จึงไม่ใช่ระบบออฟไลน์ทั้งหมด โครงการนำร่องคำปลุกภาษารัสเซียและ Silero Baya ไม่แจกจ่ายค่าน้ำหนักโมเดลส่วนตัว

- **[ha-echo-dot](https://github.com/ha-homelab/ha-echo-dot)** — เส้นทางแปลง Echo Dot 2 เป็น EchoLocal พร้อมเครื่องมือฝึกคำปลุกและประเมินบนสภาพแวดล้อมรันจริงที่ตรงกัน

- **[ha-echo-show-5](https://github.com/ha-homelab/ha-echo-show-5)** — แปลง Echo Show 5 Gen2 เป็น Android ตรวจสอบข้อมูลสำรอง และตั้งค่า Home Assistant Companion การทดลองคำปลุก ONNX แบบวลีเดียวที่เลือกเปิดใช้ได้ผ่านการตรวจสอบซอฟต์แวร์ แต่ยังรอการทดสอบยอมรับเส้นทางเสียงตั้งแต่ต้นจนจบ

- **[ha-lg-tv-capture](https://github.com/ha-homelab/ha-lg-tv-capture)** — เครื่องมือจับภาพหน้าจอ LG webOS ที่ใช้ซ้ำได้และการเชื่อมต่อ Home Assistant

EchoLocal และ EchoMuse เป็นคนละเส้นทางการแปลง อ่านข้อกำหนดรุ่นอุปกรณ์และการกู้คืนของโครงการที่เลือกก่อนแก้ไขอุปกรณ์

### การเชื่อมต่ออุปกรณ์ บริดจ์ และการกู้คืน

- **[ha-radio-hub](https://github.com/ha-homelab/ha-radio-hub)** — ต้นแบบ PoE แบบโมดูลาร์ MC2-C + FH1 รุ่นปัจจุบัน มีเสาอากาศภายนอกอิสระสามต้นสำหรับ Zigbee, Thread และ Bluetooth, Thread Border Router ภายในระบบ, Z-Wave, RF 433 MHz และการตรวจวัด มี CAD เฟิร์มแวร์และเครื่องมือปรับใช้ให้ แต่ยังรอการตรวจสอบฮาร์ดแวร์จริง

- **[ha-desloc](https://github.com/ha-homelab/ha-desloc)** — ส่วนเชื่อมต่อคลาวด์ DESLOC ที่ไม่เป็นทางการสำหรับสถานะล็อก การควบคุม แบตเตอรี่ และ Wi-Fi โดย[ความเข้ากันได้ต่างกันตามรุ่น](https://github.com/ha-homelab/ha-desloc/blob/main/docs/compatibility.md)

- **[ha-desloc-card](https://github.com/ha-homelab/ha-desloc-card)** — การ์ดแดชบอร์ดแยกต่างหากพร้อมตัวแก้ไขภาพ การทำงานตามสถานะ และการยืนยันปลดล็อก

- **[rf-airbridge](https://github.com/ha-homelab/rf-airbridge)** — เกตเวย์ ESPHome CC1101 สำหรับข้อมูลสังเกต RF ผ่าน MQTT การส่งผ่าน ESPHome โดยตรง และระบบอัตโนมัติ Home Assistant

- **[zigbee-direct-button](https://github.com/ha-homelab/zigbee-direct-button)** — เฟิร์มแวร์ปุ่ม Tuya สำหรับควบคุมกลุ่ม Zigbee โดยตรง กดสั้นเพื่อสลับและกดค้างเพื่อปิด ดู[ขอบเขตการตรวจสอบอุปกรณ์จริงในปัจจุบัน](https://github.com/ha-homelab/zigbee-direct-button/blob/main/docs/validation.md)

- **[ha-tuya-esphome](https://github.com/ha-homelab/ha-tuya-esphome)** — แปลงปลั๊ก ESP8266 รุ่นเก่า สถานีแฟลช Linux ที่ทำซ้ำได้ และคู่มือบริดจ์ Matter

- **[zac93-esp32](https://github.com/ha-homelab/zac93-esp32)** — แบบบริดจ์ Zooz ZAC93 พร้อมภาพประกอบสำหรับ ESP32-WROOM/S3, ESPHome และ Z-Wave JS

- **[slzb-06-recovery](https://github.com/ha-homelab/slzb-06-recovery)** — สำรอง อัปเกรด และกู้คืนผ่าน Ethernet แบบเดิมสำหรับ SLZB-06 รุ่นต้นฉบับ เฟิร์มแวร์แกนหลักและวิทยุเป็นคนละเป้าหมาย

### เครื่องมือวางผัง การตรวจวัด และการเข้าถึง

- **[home-studio](https://github.com/ha-homelab/home-studio)** — วาดและจัดเฟอร์นิเจอร์ในห้องภายใน Home Assistant โดยตรง บันทึกแบบร่างที่แก้ไขได้ และเผยแพร่มุมมอง 3D Home
- **[ruview-home-sensing](https://github.com/ha-homelab/ruview-home-sensing)** — การเก็บ CSI แบบทดลอง เฟิร์มแวร์ตัวรับ สมมติฐานเกี่ยวกับกิจกรรม และเครื่องมือตรวจสอบหลักฐานการอนุมาน เผยแพร่ผ่าน ruview-home-assistant และไม่ได้ยืนยันความแม่นยำในการตรวจจับในสภาพจริง

- **[sensing-evidence-kit](https://github.com/ha-homelab/sensing-evidence-kit)** — บันทึก ติดป้าย และเปรียบเทียบข้อมูลสังเกต โดยตรวจความสดของข้อมูลและนาฬิกาอย่างชัดเจน

- **[ruview-home-assistant](https://github.com/ha-homelab/ruview-home-assistant)** — ข้อมูลสังเกต RuView ผ่าน MQTT discovery การตรวจความสดรายโหนด และตัวอย่างเล่นซ้ำข้อมูลสังเคราะห์

- **[ha-onvif-room-direction](https://github.com/ha-homelab/ha-onvif-room-direction)** — ประเมินบริเวณจากทิศทางกล้องที่อ่านอย่างเดียว ส่วนพื้นที่ที่กำหนด และการตรวจความสดของข้อมูล

- **[ha-access-session](https://github.com/ha-homelab/ha-access-session)** — เซสชัน Cloudflare Access ที่ตรวจสอบแล้วสำหรับแดชบอร์ดภายนอก และโทเคนอายุสั้นผ่านเกตเวย์จำกัดขอบเขต โดยผูกกับผู้ดูแล Home Assistant หนึ่งรายที่กำหนดไว้อย่างชัดเจนและมีสิทธิ์เต็ม ความสามารถเสริมในการให้ภาพประกอบของเครื่องเล่นสื่อผ่านการยืนยันตัวตนปิดอยู่โดยค่าเริ่มต้น

ตัวอย่างการตรวจวัดอธิบายสิ่งที่สังเกตและข้อจำกัด การเล่นซ้ำข้อมูลสังเคราะห์และทิศทางกล้องไม่ได้พิสูจน์ความแม่นยำในการตรวจการมีคนอยู่ในสถานการณ์จริง

## โครงการสาธารณะที่เกี่ยวข้องนอกองค์กรนี้

โครงการที่ดูแลแยกกันเหล่านี้ช่วยเสริม homelab เป็นส่วนประกอบเสริมที่เลือกใช้ได้ โดยมีการตั้งค่าและขอบเขตสนับสนุนของตนเอง

**พลังงาน — [ระบบนิเวศ Victron / Venus OS](https://github.com/victron-venus)**

- [inverter-climate](https://github.com/victron-venus/inverter-climate) ประสานการควบคุมสภาพอากาศผ่าน Home Assistant และ Venus OS โดยค่าเริ่มต้นเป็นการสังเกตอย่างเดียว

- [dbus-emporia-vue](https://github.com/victron-venus/dbus-emporia-vue) เผยค่าที่วัดจากวงจรเป็นโหลด GX; [dbus-pump](https://github.com/victron-venus/dbus-pump) เชื่อมเอนทิตีถัง ปั๊ม และวาล์วของ HA

- [inverter-dashboard-go](https://github.com/victron-venus/inverter-dashboard-go) ให้แดชบอร์ดพลังงานพร้อม UI แบบ Vue และอุปกรณ์ Home Assistant ที่เลือกเชื่อมได้

**เสียงและสื่อ — รวม[ระบบนิเวศ Open OTT Play](https://github.com/open-ott-play)**

- [Amazon Echo Home Energy](https://github.com/4alvit/amazon-echo-home-voice) เป็น Alexa custom skill แบบอ่านอย่างเดียว; [Google Home / Nest reports](https://github.com/4alvit/google-home-voice-stats) ส่งวิดีโอ Cast พร้อมเสียงสังเคราะห์ภายในเครื่อง ทั้งสองทำงานโดยไม่ต้องดัดแปลงฮาร์ดแวร์ Home Assistant เป็นตัวเลือก และ Alexa skill ไม่จำเป็นต้องใช้ Home Assistant

- [EPG Voice Gateway](https://github.com/4alvit/epg-voice-gateway) ค้นหารายการ XMLTV ที่กำลังออกอากาศและส่งการเล่นผ่านพร็อกซี HLS ที่มีอยู่ไปยังหน้าจอ Alexa หรือ Google Cast

- [OTT-play Control Server](https://github.com/open-ott-play/ottplay-control-server) ให้คำสั่งเครื่องเล่น การควบคุมผ่านเทอร์มินัล และการติดตั้ง k3s เกตเวย์ EPG ไม่ขึ้นกับ OttPlay
- [Cisco Home Telephony](https://github.com/4alvit/cisco-home-telephony) — ให้การเตรียม Cisco 7945G สำหรับ SIP, Asterisk บน k3s, CLI โทรศัพท์ และขั้นตอนเสียง/การควบคุม Home Assistant แบบเลือกใช้

**โครงสร้างพื้นฐานที่ใช้ซ้ำได้**

- [ESPHome BLE Sensor Patterns](https://github.com/4alvit/esphome-ble-sensor-patterns) ให้การตั้งค่า ESP32 อ้างอิงสำหรับเซนเซอร์แบตเตอรี่ อุณหภูมิ และต้นไม้

- [FastAPI MQTT Gateway](https://github.com/4alvit/fastapi-mqtt-gateway) เชื่อม REST/WebSocket กับ MQTT พร้อมการยืนยันตัวตนและข้อจำกัดหัวข้อ

- [MQTT Observability](https://github.com/4alvit/mqtt-observability-opentelemetry) สังเกต MQTT และตัวชี้วัด Mosquitto ผ่าน OpenTelemetry, Prometheus และ Grafana ไม่ใช่พร็อกซีข้อความ

- [HA Homelab Terraform](https://github.com/4alvit/terraform-github-ha-homelab) จัดการการตั้งค่า GitHub และที่เก็บโครงการขององค์กรนี้
- [Venus OS CI Toolkit](https://github.com/victron-venus/venus-os-ci-toolkit) — ให้เวิร์กโฟลว์ GitHub Actions ร่วมและเครื่องมือ CI สำหรับการตรวจสอบ การออกรุ่น และการตรวจความปลอดภัย โครงการที่ใช้งานจะตรึง commit ที่ผ่านการทบทวนแล้ว

## วิธีทำงานของเรา

รักษาพฤติกรรมให้เข้าใจได้ การเปลี่ยนแปลงให้ตรวจทานได้ บิลด์ให้ทำซ้ำได้ และมีเอกสารกู้คืน ตัวอย่างและภาพหน้าจอสาธารณะใช้ข้อมูลสังเคราะห์ในจุดที่ระบุ ข้อมูลรับรองของบ้าน เสียงบันทึก ข้อมูลสำรองอุปกรณ์ และข้อมูลส่งออกการปฏิบัติงานส่วนตัวอยู่นอกที่เก็บเหล่านี้ แต่ละโครงการระบุสิ่งที่ทดสอบแล้วและสิ่งที่ยังต้องตรวจอุปกรณ์จริง

ร่วมพัฒนาตามคู่มือของที่เก็บที่เกี่ยวข้อง และรายงานช่องโหว่ตามนโยบายความปลอดภัยของโครงการ ที่เก็บนี้ยังเก็บ[โลโก้ต้นฉบับและบันทึกการออกแบบ](https://github.com/ha-homelab/.github/blob/main/assets/README.md)
