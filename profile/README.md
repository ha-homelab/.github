<h1 align="center">HA Homelab</h1>
<p align="center">A thoughtful home. Understandable automation.</p>

We maintain a personal Home Assistant homelab with clear configuration,
reusable scripts, and automation that is easy to understand and maintain.

## How we work

- **Predictable behavior.** Preserve working behavior while improving the configuration.
- **Clear intent.** Document what each automation does, why it exists, and how to verify it.
- **Stable identities.** Keep identifiers and references consistent across configuration.
- **Reviewable changes.** Use version control, validation, and deliberate deployment.
- **Private by default.** Keep household configuration and operational details in private repositories.

## Repositories

For organization members:

- [Automations](https://github.com/ha-homelab/automations) — event-driven Home Assistant behavior.
- [Scripts](https://github.com/ha-homelab/scripts) — reusable actions and sequences.
- [Home Assistant](https://github.com/ha-homelab/home-assistant) — configuration and deployment guidance.

Our public [GitHub infrastructure](https://github.com/4alvit/terraform-github-ha-homelab)
is managed with Terraform and runs in HCP Terraform. This profile repository holds
our [original logo and design notes](https://github.com/ha-homelab/.github/blob/main/assets/README.md).
